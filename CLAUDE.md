# My Project

This project uses the rex harness. Key locations:

- Active project: `rex/active/project.yaml`
- Skills: `.claude/skills/`
- Agents: `.claude/agents/`

## Project directories

- `assets/`
- `examples/`
- `rex/`
- `src/`
- `target/`

## Working with rex

Run `rex create` to start a new project.
Run `rex activate <project-id>` to switch to an existing project.
Run `rex init` to update the harness bundle.
